# ตำโมจิ — commands

Gift commands for the free AVO Play live game **ตำโมจิ** (mochi pounding).

**Page:** https://aotgtr.github.io/mochi-commands/

Each command is a word with an optional number (`order 1`, `help 45`, `speed 60`, `random order 1 25`, `random help 10 60`). Copy it into a gift rule in AVO Play.
